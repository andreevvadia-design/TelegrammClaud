# Python-плагины claud code
Настройки → ⋮ → Плагины claud code → Импортировать плагин → выбрать hello_claud.py → Включить.

Формат: обычный .py до 256 КБ; строковые метаданные __id__, __name__, __version__, __description__; один класс-наследник BasePlugin. Метаданные читаются AST без исполнения кода.
API: on_plugin_load(), on_plugin_unload(), on_event(name, payload), get_setting(key, default), set_setting(key, value). Состояние и JSON-совместимые настройки сохраняются локально. Событие app_started отправляется при запуске процесса; settings_title позволяет менять заголовок настроек (payload — строка). Пример hello_claud.py изменяет заголовок при следующем открытии настроек.

Импорт/обновление не включает плагин автоматически. При ошибке загрузки/события он выключается. После перезапуска включённые плагины восстанавливаются. Обновление и удаление выгружают плагин.
Python/Java interop имеет права приложения; это не песочница. Блокирующий или аварийно завершающий процесс код не изолирован.

Это собственный API v1, а не полная совместимость exteraGram: Xposed hooks, SDK exteraGram, события отправки сообщений и пользовательские экраны настроек ещё не реализованы.
Среда: Chaquopy 17.2, Python 3.11, Android 7+ (API 24). APK не проверен на устройстве.

UI-настройки: create_settings() возвращает Header(text), Switch(key, text, default), Input(key, text, default) из ui.settings. Они доступны в меню плагина → Настройки; плагин должен быть включён. Поддержаны export_settings/import_settings и logger.
AppEvent.START/PAUSE/RESUME доступны через on_app_event; STOP не гарантируется Android. Утилита android_utils.run_on_ui_thread вызывает код на UI-потоке.
После прерванного события плагин выключается при следующем запуске. Это восстановление после перезапуска, не изоляция зависшего кода.

Ручное восстановление: кнопка «Выключить все при следующем запуске» записывает флаг независимо от очереди Python. После полного перезапуска включённые плагины не загружаются.

## Расширение .plugin
Импорт в существующем APK принимает файл независимо от расширения: hello_claud.plugin содержит тот же Python-код и работает через текущий движок. Внутри хранилища файл нормализуется в <id>.py. Расширение .plugin не означает Java или совместимость со всем SDK exteraGram.
